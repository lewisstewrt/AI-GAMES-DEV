AI Games Development - Assignment 1 (LLM GAME)

Overview
This project is for the first assignmnet in our AI Games devlepment module.

Our aim is to develop a tic tac toe game that integrates an LLM to create dynamic gameplay.



Our Planned Features

Player vs LLM turn based system
Chat-driven AI decisions
SDL3 Graphical interface
Imgui UI integration


Technologies used

C++
SDL3
ImGui
CMake

How to Run

Clone repository
Open project in Visual Studio
Build using CMake
Run the executable

Project Status
